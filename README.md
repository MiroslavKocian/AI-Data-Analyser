# 🚀 AI-Sales-Analyser
### Transitioning from Legacy RPA to a 2026 GenAI Stack

## 📌 Project Overview
This project demonstrates a bridge between traditional **RPA (Blue Prism/IBM)** enterprise environments and modern **AI-driven automation**. It replaces fragile "click-based" workflows with "thought-based" data processing.

## 🛠️ The Solution
- [cite_start]**Data Normalization:** Converts "dirty" legacy Excel exports (inconsistent dates, currency strings) into clean, structured data using LLMs.
- [cite_start]**SQL Warehouse:** Persists cleaned data into a structured **SQLite** database for permanent storage and high-speed querying.
- [cite_start]**Multilingual Intelligence:** A Streamlit interface that accepts natural language queries in **Slovak, English, or French** and converts them instantly to SQL.

## 💻 Tech Stack
- **Python 3.11**
- **Streamlit** (UI)
- **SQLite** (Database)
- **Groq / Llama 3.1** (LLM Engine)
